# Phase 2 — Native Wrapper

Pocket Barista now has a Capacitor wrapper configuration so the existing Vite app can be packaged for iOS and Android without rewriting the web UI.

## Local setup

From the repository root:

```bash
npm install
npm run build
npm run cap:add:ios
npm run cap:add:android
npm run cap:sync
```

Then open the native projects:

```bash
npm run cap:open:ios
npm run cap:open:android
```

## Native identifiers

- App name: `Pocket Barista`
- iOS/Android app ID: `com.pocketbarista.app`
- Web build directory: `dist`

The `ios/` and `android/` directories are generated by Capacitor on the developer machine. They should be created with the Capacitor CLI so the native projects match the installed Capacitor version and the local Xcode/Android tooling.

## Phase 2 target

This phase establishes the native shell around the existing Pocket Barista app. Native-only features such as haptics, share sheets, local notifications, filesystem access, and store-specific configuration can be added as the next native layer without changing the core recipe/journal experience.
